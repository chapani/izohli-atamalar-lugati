# Ihotali Muhit

**Inglizça:** Sandbox<br>
**Rusça:** Песочница<br>
**Aloqali:** Sinov<br>
**Soha:** Dasturlov<br>

**Ihotali Muhit** — bitik yoki dasturning qolgan tizimdan ajratilgan, nazorat ostidagi ijro muhiti. Ihotali muhit içida işlayotgan dastur fayllar, tarmoq yoki boşqa zahiralarga faqat ruhsat etilgan darajada murojaat qila oladi. Bu havfsizlikni oşiriş, nomalum bitiklarni tekşiriş va tajribalarni asosiy tizimga zarar yetkazmasdan ötkaziş imkonini beradi. Ihotali muhit sinov, nuqsonsizlov va havfsiz ijro vazifalarida keng qöllanadi.

```text
 ┌─────────────────────┐
 │ Fayllar             │

 │ Boşqa zahiralar     │
 └─────────┬───────────┘
           │
     Çeklangan kiriş
           │
   ┌───────▼───────┐
   │ Ihotali Muhit │
   │ ┌───────────┐ │
   │ │   Bitik   │ │
   │ └───────────┘ │
   └───────────────┘
```

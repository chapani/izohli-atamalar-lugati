# Tafovut

**Inglizça:** Diff<br>
**Rusça:** Разница (Дифф / Сравнение файлов)<br>
**Soha:** Dasturlov<br>

**Tafovut** — ikki fayl, bitik yoki qaydlar örtasidagi farqlar va özgarişlar töplami. Git kabi versiyalarni boşqaruv tizimlarida manba bitikdagi qöşilgan, öçirilgan yoki özgartirilgan satrlarni körsatiş uçun işlatiladi. Dasturçilarga qilingan tuzatişlarni közdan keçiriş va qaydlardan oldin hatoliklarni aniqlaşga yordam beradi.

```text
[Eski fayl]          [Yangi fayl]
  let a = 1;           let a = 1;
- let b = 2;         + let b = 3;
                     + let c = 4;
───────────────────────────────────
Tafovut:
-1 satr öçirilgan,
+2 satr yangidan qöşilgan

```
